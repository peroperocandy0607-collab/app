## 2. 伝統的な「くくり」に対する充足度

天使は、「くくり」で語られることが多く、そのくくりが揃っているかを見ると、抜けが分かります。

| くくり | 顔ぶれ | 揃い具合 |
|---|---|---|
| 三大天使 | ミカエル・ガブリエル・ラファエル | **3/3 ✅** |
| 四大天使 | 上の3人＋ウリエル | **4/4 ✅** |
| 七大天使（『エノク書』の顔ぶれ） | ミカエル・ガブリエル・ラファエル・ウリエル・ラグエル・レミエル・サラカエル（＝サリエル） | **7/7 ✅** |
| 七大天使（ルネサンス期の顔ぶれ） | 三大天使＋ウリエル・セアルティエル・イェフディエル・バラキエル | **7/7 ✅** |
| 七曜の天使（西洋の伝統の一例） | 日：ミカエル／月：ガブリエル／火：カマエル／水：ラファエル／木：**サキエル**／金：アナエル／土：カシエル | **6/7**（木曜のサキエルだけ不足） |
| 天使の九階級の「長」 | 熾：セラフィエル／智：ケルビエル／**座：ザフキエル**／主：ザドキエル／**力：（資料により異なる）**／能：カマエル／権：ハニエル／大：ミカエル／**天使：（資料により異なる）** | 6/9（座・力・天使が不足） |
| 十二星座の天使（西洋の伝統の一例） | 射手座：アドナキエル／蟹座：ムリエル？／ほか9人 | **1〜2/12**（ムニエルがムリエルと同じかは不明） |

※七曜・九階級・十二星座の割り当ては、資料によって違います。上は一例です。

## 3. 不足している有名どころ（検索の実測つき）

サジェストの数は、その名前で検索されている広がりの目安です（ボリュームの数値ではありません）。アニメ・ゲームなどの「別のもの」の検索が混ざる名前は、備考に書きました。

### A. 追加をおすすめ（このシリーズに入れる）

| 天使 | 理由 | サジェスト実測 | 備考 |
|---|---|---|---|
| **チャミュエル** | 現代のオラクルカードで人気の大天使。愛や探し物のテーマで知られる。今回のカードにない | 15件（チャミュエルナンバー、探し物、大天使、守護天使…） | 「カマエル」と混同されやすい別の天使 |
| **サキエル** | 七曜の天使で、木曜が抜けている。「智天使サキエル」とも検索される | 17件（サキエルとは、天使、意味…） | アニメの使徒の名前としても検索される |
| **ザフキエル（ツァフキエル）** | 座天使の長。九階級の抜けを埋められる | 14件（ザフキエルとは、能力、意味…） | ゲーム・アニメの作品名も混ざる |
| **ジェレミエル** | 今はレミエルの記事の中で触れただけ。独立した記事の需要がある | 8件（ジェレミエルとは、大天使、役割、メッセージ…） | レミエルと同一視する資料が多い。記事は差別化が必要 |

### B. 別シリーズ向き（検索は多いが、性質が違う）

| 天使 | サジェスト実測 | 備考 |
|---|---|---|
| **ルシファー／ルシフェル** | 35件／26件（とは、意味、役割、天使…） | **検索は、抜群に多い。** ただし堕天使で、シリーズの雰囲気が変わる。「堕天使シリーズ」として別に立てるのが安全 |
| **サマエル** | 20件（サマエルとは、悪魔、天使、ミカエル…） | 「死の天使」の別名とされることもあり、アズラエルとの関係も書ける |
| **アザゼル** | 22件（アザゼルとは、悪魔、天使…） | 『エノク書』の堕ちた見張りの長 |
| **アバドン** | 12件（アバドンとは、天使、堕天使…） | 黙示録に登場する「底なしの淵の使い」 |

### C. まとめ記事（ハブ記事）としておすすめ

個々の天使より、**「くくり」の言葉のほうが検索されています。** 今回の30本へ内部リンクを張る、親記事にできます。

| 記事案 | サジェスト実測 | 中身のイメージ |
|---|---|---|
| **守護天使とは** | 19件（一覧、意味、役割…） | 守護天使の考え方と、30天使への入口 |
| **七大天使とは（一覧）** | 12件（一覧、名前、能力、美徳、階級…） | 二つの顔ぶれの比較表（§2）と、各天使への案内 |
| **四大天使とは** | 13件（役割、階級…） | ミカエル・ガブリエル・ラファエル・ウリエルの違い |
| **三大天使とは** | 8件（役割、階級、名前…） | 最初に読む入門記事 |
| **天使の九階級とは（熾天使・智天使・座天使…）** | 熾天使17／座天使13／智天使12／力天使12／能天使11／権天使10／主天使8 | 階級ごとの解説と、長の天使への案内。**階級名の単独検索が多い** |

### D. 優先度が低い・入れないほうがいい

| 名前 | 理由 |
|---|---|
| **十二星座の天使（マルキダエル、アスモデル、アンブリエル、ヴェルキエル、ハマリエル、ズリエル、バルビエル、カンビエル）** | サジェストはほぼ0〜9件で、検索されていない。個別記事より、「星座ごとの守護天使一覧」1本にまとめるほうが効率的。占いサイトとの相性はよい |
| **ファヌエル** | 『エノク書』の四大天使のひとりだが、検索はブランド名が中心（9件） |
| **リリス、ベルゼブブ** | 天使ではない（リリスはユダヤの伝承の女性、ベルゼブブは悪魔）。天使シリーズには入れない |
| **ラミエル** | レミエルの別表記。エヴァの使徒の検索が中心。レミエル記事でカバー済み |
| **ジブリール、ミカイール** | ガブリエル、ミカエルのイスラム教での呼び名。各記事でカバー済み |

## 4. まとめ：おすすめの順番

1. **ハブ記事5本**（三大天使／四大天使／七大天使／守護天使／九階級）。検索されやすい「くくり」の言葉で、30本へ内部リンクを集める
2. **不足の天使4人**（チャミュエル、サキエル、ザフキエル、ジェレミエル）。七曜と九階級の穴を埋める
3. **堕天使シリーズ**（ルシファー、サマエル、アザゼル、アバドン）。検索は多いが、別枠で
4. **星座天使の一覧**（1本）

## 5. 注意

- サジェストで分かるのは「検索されている」ことだけです。**検索ボリュームの数字は取っていません。**
- 「七曜の天使」「十二星座の天使」「九階級の長」の割り当ては、資料によって違います。記事にする時は「一例」と書くのが安全です
- 名前が有名でも、アニメ・ゲームの検索が多い名前（サキエル、ザフキエルなど）は、実際の流入が、天使に興味のある人ばかりとは限りません
